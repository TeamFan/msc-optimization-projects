# Online Learning — Generalized Weighted Averaging for Nonsmooth Convex Optimization

Project for the *Online Learning* course. The report studies a weighted
averaging scheme in which subgradients are evaluated at an interpolation
point `z_t = β_t x̄_t + (1-β_t) x_t` between the current iterate and the weighted average,
and proves ergodic objective bounds at the averaged iterate `x̄_T` for

* mirror descent and projected subgradient descent,
* dual averaging with time-dependent parameters,
* AdaGrad-Norm,

in both the deterministic and the stochastic setting.

## Experiments

`experiments/online_experiments.py` implements all algorithms and runs three
studies (results are written to `results/`):

| Stage | Content |
|---|---|
| `svm` | Projected subgradient / dual averaging / AdaGrad-Norm with `β_t ∈ {0, 0.5, 1−1/√t}` and step schedules `c/√T`, `c/√t`, `c/t` on an even-vs-odd `digits` SVM |
| `geometry` | Euclidean vs. entropy mirror map on a simplex-constrained LAD problem, and Euclidean vs. diagonal Mahalanobis geometry on an ill-conditioned logistic regression |
| `stochastic` | Full-batch, batch-32 and single-sample regimes, plus a Gaussian noise stress test, on SVM and logistic regression |

```bash
python experiments/online_experiments.py --stage all          # ~2.5 min
python experiments/online_experiments.py --stage svm --quick  # smoke test
```

Gaps are measured against a high-accuracy reference value obtained from a
long-horizon (50 000 iterations) full-batch reference bank. The per-iteration
history files (`*_history.csv`, ~100 MB) are regenerated by the script and
are not stored in the repository.

## Main findings

* Interpolation (`β_t > 0`) consistently improves the gap to the reference
  value in the SVM schedule study, but no single `β_t` is best everywhere.
* AdaGrad-Norm is the strongest Euclidean method on the classification
  tasks and ties with projected subgradient descent on Huber regression.
* Geometry matters under poor conditioning: the diagonal Mahalanobis mirror
  map improves the ill-conditioned logistic problem by more than two orders
  of magnitude, while entropy geometry does not help on the tested simplex
  problem.
* In the stochastic study, degradation is driven by small batches rather
  than by the added Gaussian noise.
